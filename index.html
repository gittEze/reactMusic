GUÍA DE USO

Manual de usuario

Todo lo que necesitas saber para utilizar el reproductor.
🎵

Biblioteca

La biblioteca es la vista principal del reproductor. Aquí aparecen las canciones disponibles desde el repositorio y las canciones locales que hayas cargado.

🌐

Repositorio

En esta sección puedes consultar las canciones incluidas en el repositorio del proyecto. Estas canciones se cargan automáticamente en el reporductor.

💻

Música local

Puedes reproducir archivos de audio almacenados en tu computadora. Selecciona una carpeta mediante el botón 📁 Seleccionar carpeta. Los archivos compatibles serán agregados automáticamente.

Se admiten archivos MP3, WAV, OGG, M4A, AAC y FLAC.

🔎

Buscar canciones

Utiliza el buscador situado en la parte superior para encontrar rápidamente una canción. La búsqueda funciona por nombre de canción y artista.

🔀

Reproducción aleatoria

El botón 🔀 Aleatorio permite reproducir las canciones en un orden aleatorio. Puedes activarlo o desactivarlo cuando quieras.

↕

Ordenar canciones

El botón ↕ Ordenar cambia el orden de las canciones entre orden alfabético ascendente y descendente.

▶

Reproductor

Cuando seleccionas una canción, el reproductor inferior muestra su nombre, artista y portada. Desde allí puedes controlar la reproducción.

⏮Canción anterior
▶Reproducir o pausar
⏭Siguiente canción
🔊Controlar volumen
━Cambiar posición
⏱

Barra de progreso

La barra situada debajo de los controles permite ver el progreso de la canción y desplazarte hacia cualquier momento del audio.

🔊

Volumen

Utiliza la barra de volumen para aumentar o disminuir el sonido. El reproductor recuerda automáticamente el último volumen utilizado.

🗗

Mini reproductor

El botón 🗗 abre el mini reproductor en una ventana independiente cuando el navegador permite utilizar Picture-in-Picture para documentos. Desde esa ventana puedes controlar la canción, el progreso y el volumen.

⌨️

Atajos de teclado

Mientras no estés escribiendo en un campo de texto puedes utilizar:

  • Espacio: reproducir o pausar.
  • ←: canción anterior.
  • →: siguiente canción.
⚠️

Problemas frecuentes

  • Si una canción local no aparece, comprueba que tenga un formato compatible.
  • Los archivos locales solamente están disponibles mientras la página tenga acceso al archivo seleccionado.
  • Si el mini reproductor no se abre, es que tu navegador no es compatible.
  • Si no se escucha el audio, revisa el volumen del reproductor y el volumen general del sistema.
